## Outstanding Review

Before publication, record the exact versions of any adapted notebook/snippet, its license, the local adaptation, and any required copyright/NOTICE text. Public availability is not a substitute for a license. Review the pinned dependencies and their upstream licenses too; package metadata alone is not a complete review.

The proposed project MIT license applies only to original work the owner is entitled to license. Third-party code/data/artifacts retain their own terms. Neither these links nor the automated repository checks approve public release.
